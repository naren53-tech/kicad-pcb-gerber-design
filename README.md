# 🛠️ PCB Design & Gerber Generation using KiCad

## 📌 Project Overview

This project demonstrates the design of a printed circuit board (PCB) using KiCad and the generation of Gerber files required for manufacturing.

---

## 🧰 Tools Used

* KiCad (Schematic & PCB Design)

---

## 🔄 Workflow

1. Created schematic in KiCad
2. Converted schematic to PCB layout
3. Routed tracks and finalized board design
4. Defined board outline using Edge.Cuts layer
5. Generated Gerber files for fabrication
6. Exported drill files (PTH & NPTH)

---

## 📁 Generated Files

* Top Copper (F.Cu.gbr)
* Bottom Copper (B.Cu.gbr)
* Board Outline (Edge_Cuts.gbr)
* Drill Files (.drl, PTH, NPTH)
